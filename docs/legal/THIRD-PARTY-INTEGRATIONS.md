# Third-party integration disclosure (draft)

**Current version (0.1.0): no third-party integrations.** No cloud sync, no AI services, no CRM, no analytics or advertising providers, no accounts. The only shipped third-party code is the React library (MIT), bundled locally.

Before any integration is enabled, the user will be shown, and must separately authorize: the receiving service and its location; exactly what information is shared and why; the provider's retention and model-training practices (stated only if verified); how to disconnect and what happens to already-shared data. Saved messages will never be sent to an AI service without an explicit user action or a clearly disclosed processing arrangement.
