# Doc 8: Master Quality Assurance Checklist

Version 0.1, 27 November 2026. Every video, every platform version, before Ready for Review. Record the result in the tracker (QA Status) with the failed item codes.

## Message
- [ ] M1 The hook lands in the first 3 seconds (spoken and on screen).
- [ ] M2 The video delivers what the hook promises.
- [ ] M3 Approved caption, script and CTA preserved; any change flagged for approval.
- [ ] M4 No invented numbers, results, testimonials or software features. Every claim is real and approved.
- [ ] M5 Client names, results and testimonials have written permission on file.
- [ ] M6 Demo label on screen for any demo with fictional data.
- [ ] M7 Affiliate disclosure on screen and in the post copy (affiliate videos).

## Edit
- [ ] E1 No dead air, false starts or repeated sentences left; natural pauses that matter kept.
- [ ] E2 A visual change at the pace set for the content type (Doc 4).
- [ ] E3 B roll supports what is being said.
- [ ] E4 No unnecessary effects; max one graphic plus captions on screen.

## Audio
- [ ] A1 Integrated loudness -14 LUFS (plus or minus 1), true peak at or below -1 dBTP (render report or `ffmpeg -af ebur128`).
- [ ] A2 Voice clear; no hum, clicks or clipped words at cuts.
- [ ] A3 Music under the voice and licensed for this platform.

## Captions
- [ ] C1 Spelling and timing correct, checked against the audio.
- [ ] C2 Max 4 words per screen; keywords highlighted in yellow, not every other word.
- [ ] C3 Tagalog and Bisaya lines checked by a human.
- [ ] C4 Captions do not cover the face, product or the interface element being discussed.
- [ ] C5 No dashes in on screen text. SRT exported.

## Brand
- [ ] B1 Fonts: Manrope ExtraBold, Instrument Serif italic accent, Inter only.
- [ ] B2 Colours from the v2 palette only. No gold, blush or beige. No emojis.
- [ ] B3 Official logo file, unmodified, correct version for the background, minimum size and clear space respected.
- [ ] B4 Looks recognisably Kryz with the logo covered.

## Platform
- [ ] P1 Correct size, frame rate and duration for the platform.
- [ ] P2 All text and graphics inside the platform safe zone.
- [ ] P3 Cover or thumbnail made; Reel cover text readable in the grid crop.
- [ ] P4 Thumbnail readable at small size (check at 168x94).
- [ ] P5 Platform specific caption, title, CTA and hashtags written.

## Technical
- [ ] T1 Plays start to finish with no glitches, black frames or frozen frames.
- [ ] T2 Audio in sync at the start, middle and end.
- [ ] T3 File named per Doc 7; correct version number.

## Privacy and rights
- [ ] R1 No confidential client data, emails, phone numbers, passwords, invoices or private messages visible (pause through every screen recording).
- [ ] R2 Footage, music, fonts and images are owned or licensed.

## Delivery
- [ ] D1 Files uploaded to the right Drive folder and open correctly from Drive.
- [ ] D2 Editable project files saved in 10.
- [ ] D3 Tracker updated.
- [ ] D4 Not published. Publishing only with explicit authorisation.
